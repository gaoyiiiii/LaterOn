## LaterOn 能做什么

| 一键添加 | 按项目整理 | 随时继续浏览 |
| --- | --- | --- |
| 按 `Alt+1` 添加当前网页，按 `Alt+Shift+1` 添加当前窗口的所有标签页。 | 添加时选择项目，或者先放进“等待整理”；支持拖拽和多选移动。 | 在全屏界面管理，在浏览器侧栏继续浏览；再次打开网页时可以继续上次滚动位置。 |

LaterOn 会自动提取网页标题、摘要、封面和来源。已经打开的网页不会重复创建标签页，而是直接切换到现有页面。YouTube 按视频 ID 识别同一视频，短链接、播放列表和播放时间参数的差异不会重复打开，也不会重置已打开视频的播放位置。

## 1 分钟安装

LaterOn 目前通过开发者模式安装，支持 Chrome / Edge 121 及以上版本。

1. [下载项目 ZIP](https://github.com/gaoyiiiii/LaterOn/archive/refs/heads/main.zip) 并解压。
2. 打开 `chrome://extensions/`；Edge 使用 `edge://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `LaterOn-main` 文件夹。
5. 建议在扩展菜单中固定 LaterOn，点击图标即可打开侧栏。

## 日常使用

| 操作 | 方式 |
| --- | --- |
| 添加当前网页 | `Alt+1`，或网页右键菜单 |
| 添加当前窗口全部标签页 | `Alt+Shift+1` |
| 打开 LaterOn | 点击浏览器工具栏图标 |
| 搜索网页 | 地址栏输入 `lo`，按空格后输入关键词 |
| 在新标签页打开 | `⌘/Ctrl + 点击`文章卡片，或使用卡片右键菜单 |

快捷键可以在 `chrome://extensions/shortcuts` 中重新设置。

## 核心体验

- **等待整理**：没想好放在哪里时先添加，之后再统一归类。
- **全部项目首页**：用图板快速浏览所有项目，并直接新建项目。
- **侧栏继续浏览**：点击顶部“添加”将当前网页加入 LaterOn，已有网页显示“已添加”。切换浏览器标签页时，LaterOn 会自动定位到当前网页及其所属项目，并将横向项目栏中选中的项目滚入可视范围；阅读状态等数据刷新会保留当前选择的项目。
- **项目归档**：归档项目会从普通项目列表和搜索中隐藏，可在全屏界面的“归档”中查看、搜索和恢复。归档中的已读网页仍按设置的期限自动清理；删除项目会同时永久删除其中的网页，操作前会确认。
- **阅读状态**：区分未读、在读和已读；已读内容默认 30 天后自动清理，可在设置中调整。
- **继续上次位置**：重新打开读过的网页时，由你决定是否回到上次滚动位置。
- **批量处理**：多选后可移动、标记、删除，或在一个新窗口中打开。批量删除会先确认，取消时保留勾选，确认后删除本次选中的网页，并一并清理上传封面。添加、修改与删除使用后台最新数据提交；写入失败时保留原数据并提示重试。
- **中英文界面**：可以在设置中切换中文 / English。

## 数据与隐私

- 网页、项目、阅读状态和设置保存在浏览器本地的 `chrome.storage.local` 中。
- LaterOn 不要求注册账号，也不会把添加的网页上传到 LaterOn 服务器。开启 AI 后，相关信息会发送到你自己配置的服务，见下方说明。
- 可以在设置页中清空全部本地网页数据。

## AI 网页整理

左下角依次为“归档 → 模型 → 设置”。在“设置”中开启 AI 功能，然后在“模型”中配置两个独立能力：

| 能力 | 可选渠道 |
| --- | --- |
| 网页提取 | 浏览器本地提取（无需 API）、DeepSeek Fetch、Tavily Extract |
| 归类判断 | OpenAI / Anthropic 兼容 Chat；TypeSafe Jev、OpenRouter Jev、OpenAI Decisions |

归类判断统一使用一个所选渠道，不区分“日常整理”和“精读归类”档位。可以选择推理模型的 Chat 接口，或 Jev／OpenAI Decisions 决策接口。Chat 提供 OpenAI、DeepSeek、通义千问、OpenRouter、Anthropic 和自定义服务预设；请在对应服务中使用已开启推理能力的模型，模型名称和连通测试本身不证明推理模式已开启。

“模型”页上方选择运行组合，下方管理渠道：同一判断方式或服务商可以保存多个独立端点，分别设置地址、密钥和模型，点击列表只切换编辑对象。模型 ID 可以手填，下拉列表提供该服务商已保存渠道中使用过的模型，不代表服务商的实时模型目录。

填写并测试后保存渠道，在上方选择一个提取渠道和一个判断渠道，再点击“保存并启用”。后续切换渠道或更新正在使用的配置，需要点击“应用更改”；未应用前继续使用原组合。删除当前渠道会暂停 AI，不会自动切换备用渠道。测试会请求真实服务并可能产生费用，使用固定公开网页或虚构分类数据，不发送你的收藏。连接测试不代表分类准确率。

新建项目必须填写名称和简介。简介描述该项目收录的主题、范围和排除内容；启用 AI 前须补全所有未归档项目的简介。导入或恢复归档带来缺失简介的项目时，AI 会暂停，补全后恢复。历史项目和收藏不会被自动重写。

AI 就绪后，`Alt+1`、`Alt+Shift+1` 和右键菜单收藏会先保存网页，再在后台提取、归类。界面“添加”保留手动项目选择，也提供独立的“AI 分类”操作。重复收藏不重新分类；明确手选项目或“等待整理”时不调用 AI。AI 不创建项目，也不覆盖原有网页摘要。

默认最低候选分数为 0.85、最低分差为 0.15，可在判断渠道的高级设置中调整。Chat 显示模型自评分，决策渠道显示接口概率，两者都不是经过 LaterOn 验证的正确率。低分、候选接近或没有合适项目时保留在“等待整理”。

远程提取失败默认回退浏览器本地提取，可以关闭此选项；不会轮询其他提取服务。判断渠道失败会报错并保留收藏，不自动重试、切换模型或调用备用渠道。收藏卡片保持原有简洁样式，不添加 AI 状态标签。“模型”页显示最近 6 条分类记录，超过 6 条时可以点击“查看全部记录”进入分类历史页，查看本机仍保留的记录。

分类记录先展示网页标题和当时的归类结果，展开后分别查看说明、网页内容来源、判断渠道和候选分数。分数列表包含“没有合适的项目”这一项；这些分数不代表分类正确率。历史记录不随手动移动网页而改写，网页的当前归属以收藏库为准。

远程提取服务会收到网页 URL；判断服务会收到清理后的网页内容和项目名称、简介。本地提取无需提取 API，但内容仍会发送到判断服务。不会向提取服务发送浏览器 Cookie 或登录凭据。密钥保存在本机可信扩展存储中，不同步、不进入收藏备份或日志；本地存储并非加密保险库。正文仅在浏览器会话内临时保留，完成后清理。

关闭 AI 会保留配置并取消未完成任务，恢复原来的收藏方式。浏览器重启后不重发旧任务；后台中断时无法确认是否完成的判断也不会自动重发，以避免重复计费。

## 开发与验证

使用项目内 Node.js 依赖：`npm ci` 会将 Readability 与许可证复制到 `vendor/`；依赖已随源码附带，直接加载扩展无需安装 Node.js。运行 `npm test` 执行模拟服务、界面与回归测试。`node scripts/mock-ai.cjs` 在本机 9417 端口提供开发模拟服务，使用固定响应，不代表真实模型效果。

打包使用 uv 管理的项目环境：`uv venv .venv`，然后运行 `.venv/Scripts/python.exe scripts/build-release.py`。输出位于 `dist/`，发布包仅包含白名单运行文件及所需许可证，不包含测试、配置密钥或浏览器测试资料。

## 常见问题

### 快捷键按下后没有反应

快捷键可能被系统或其他扩展占用。打开 `chrome://extensions/shortcuts`，为 LaterOn 换一个没有冲突的组合键。网页右键菜单不依赖快捷键，可以作为备用入口。

### 为什么有些页面不能添加？

Chrome 内部页面、扩展商店、浏览器内置 PDF 查看器等受保护页面不允许扩展注入内容。请切换到普通的 `http://` 或 `https://` 网页后再试。

### “加载已解压的扩展程序”提示找不到清单

请选择解压后直接包含 `manifest.json` 的文件夹，而不是它的上一级目录。

### 更新后界面没有变化

回到 `chrome://extensions/`，找到 LaterOn 并点击“重新加载”，然后重新打开侧栏或完整界面。

### 侧栏出现在左边，能改到右边吗？

可以。侧栏方向由浏览器控制，在 Chrome 的“设置 → 外观 → 侧栏”中修改。
