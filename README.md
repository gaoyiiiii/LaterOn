# LaterOn Chrome 扩展

一个本地优先的稍后阅读 Chrome / Edge 扩展。点击工具栏图标直接打开侧栏，可提取当前网页的标题、摘要、封面、来源与站点头像，并保存在浏览器本地。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本项目文件夹 `LaterOn`。
5. 建议点击扩展菜单中的图钉，把 LaterOn 固定到工具栏。

## 使用

- 按 `Alt+1` 可直接收藏当前网页，不打开侧边栏；页面右上角会显示收藏成功提示。“收藏当前网页前，先选项目”默认关闭，因此单篇收藏会直接进入“等待整理”。用户主动打开该设置后，快捷键、右键菜单和侧栏的“＋收藏”按钮才会先弹出项目选择浮层；选好后回车即可。
- 按 `Alt+Shift+1` 会**先在当前网页里弹出一个浮层**问你「收藏到哪个项目？」（不新开窗口）：列出现有项目和「未分类」，可以直接新建一个项目，选好后点「收藏到这里」（回车确认、Esc 取消、点灰色遮罩也能取消、双击某个项目直接开始）。**新建项目只要一步**：在输入框里写上名字，按钮会变成「新建「xxx」并收藏」，回车就直接建好并把这批收进去，不用再先点「新建」。确认后把「当前窗口」所有打开的网页收藏进去，内部页面会自动跳过、已收藏过的网址不会重复（这些**已收藏的会被一并移进你这次选的项目**，不用再手动整理；浮层顶部会提前告诉你这一批里有几篇是已收藏过的）。收藏过程是**一篇一篇顺序进行**的：先提示开始，之后每存好一篇就在网页右上角弹出一条药丸提示，工具栏角标同步累加；最后给出「新增 N 篇」的总结。以前收藏过但没抓到封面摘要的网页，会趁这次自动补全（**你亲手改过的标题、摘要除外**）；**YouTube 的重复收藏则一律用最新信息刷新**（因为 YouTube 站内跳转时它自己的分享标签不会更新，详见 `CHANGELOG.md` 的 1.21.0）——唯一例外同样是你自己改过的内容。
- 项目选择始终使用当前网页里的同一种浮层，不会再打开独立窗口。网页正在跳转时会自动重试一次；仍无法显示时会给出提示，请等页面加载完成，或切到普通网页后再试。
- 会记住你上次选的项目，下次弹出浮层时默认选中它。整窗收藏关闭“收藏前先选项目”后会使用上次选过的项目；单篇收藏只有主动打开对应开关时才会弹出浮层，否则直接进入“等待整理”。
- 不想用快捷键时，也可以在网页上点右键，选择「收藏本窗口所有标签页到 LaterOn」或「收藏此页面到 LaterOn」。
- 按 `Alt+2` 可在正文段落下方显示中文译文，再按一次恢复原文。首次使用会由 Chrome 下载本机翻译模型。
- 点击工具栏中的 LaterOn 图标会在 Chrome、Edge（Windows / macOS）直接打开或聚焦侧栏，不再弹出收藏缩略图小窗口。
- 也可以右键点击工具栏图标，选择浏览器提供的「在侧栏中打开」作为备用入口。
- 在侧边栏点击文章会在当前标签页打开，LaterOn 不会消失。
- 点击侧边栏右上角按钮进入完整卡片界面。
- 在完整界面**点一篇收藏**，不会另开标签页，而是把这个界面**切换成「原文 + 侧边栏」**：原文在当前标签页打开，侧边栏留在旁边方便接着挑下一篇（按住 `⌘`/`Ctrl` 点击则保留浏览器默认行为，在新标签页打开原文、完整界面留着不动）。
- 支持**全局搜索**：右上角搜索框里只要有字，就是在**全部收藏**里找，不受当前所在项目影响——命中结果直接铺成卡片列表（站在某个项目或图板上也会切过去，因为搜索要找的是文章、不是类目），顶部计数会写成「在全部收藏里找到 N 篇」。清空搜索就回到你原来待的地方。「未读 / 已读」那一档筛选照常生效。支持未读/已读筛选、排序、删除和阅读状态管理。
- 设置里可以切换中文 / English；语言偏好会同步应用到收藏库、侧栏和设置页。完整收藏库的图板首页称为“全部项目”（All projects）；左侧项目列表始终显示在“全部项目”下方，并通过缩进与较小尺寸明确表示从属关系，用户可以随时切换项目或把卡片拖进去。侧栏的全部文章筛选仍称为“全部内容”（All content）。新项目从图板墙末尾的虚线加号创建。等待整理在英文中显示为 “Inbox”；顶部统计只计算项目图板，不再把等待整理数量混在一起，未完成阅读统一显示为“没看完”。
- 第一次打开 LaterOn 会出现三步轻量引导，快速说明如何收藏、整理和在侧栏继续阅读。跳过或完成后不会反复打扰；需要重看时，可到设置页的“新手引导”中重新打开。
- 收藏库首页的浏览器标签标题使用“LaterOn - 没看完的网页，留到 LaterOn。”；进入等待整理、全部项目或具体项目后，标题会保留 LaterOn 前缀并切换为当前所在范围的名称。
- **标题和摘要可以自己改**：鼠标移到卡片上，右上角会浮出一支铅笔（侧边栏里也一样），点开就能改这篇的标题（单行）和摘要（多行），保存后立即生效。改过的部分会被记住——以后**再次收藏同一网址时，自动抓取的结果不会覆盖你手写的内容**（YouTube 原本一律刷新，也一样会让路）。摘要本来显示「暂无摘要」的，编辑时会变成空框方便直接补写；清空就回到「暂无摘要」。
- 完整界面支持创建项目，并为每篇收藏选择所属项目。
- 项目可以**改名**：双击名字（或按 `F2`、或右键 / 点行尾的「⋯」选「重命名」），原地输入新名字，回车保存、Esc 取消、点到别处自动保存。
- 项目可以**删除**：右键（或点「⋯」）选「删除项目」，会先弹出一个确认框（应用自己的样式，红色警示主题；回车确认、Esc 取消）。里面的收藏不会被删掉，会移到「未分类」；删除当前正在浏览的项目时会自动切回「全部收藏」。
- 所有确认与提示都用应用自己的弹窗（`dialog.js` + `dialog.css`），不使用浏览器自带的那种系统弹窗；新页面需要时引入这两个文件即可用 `LaterOnDialog.confirm(...)` / `LaterOnDialog.alert(...)`。
- 点左侧栏「项目」标题旁的「＋」新建项目；输入框会一直等你输入，点到别处或按 Esc 会自动收起。
- 可直接拖拽收藏卡片到左侧项目或“未分类”。
- 项目可以**拖拽排序**：按住任意一个项目上下拖动，松手就换到新位置（拖动时会有一条橙色指示线标出会落在哪）。顺序会保存下来，侧边栏里的项目标签也跟着一起变。
- 侧栏同步显示项目分类、数量、卡片归属及阅读状态。
- 侧栏与完整界面共享当前选中的项目，来回切换不会重置为全部。
- **点左上角的 LaterOn 标识 = 回首页**：不管当时钻在哪个项目里、筛到哪一档、搜索框里有没有字，都会回到「全部项目」图板那一屏（筛选复到「全部」、搜索清空、滚回顶部）。设置页左上角那个同样的标识也是回首页——它和右边的「返回收藏」刻意不一样：「返回」是退回上一步（保留你刚才的项目和滚动位置），Logo 是回首页（先把当前项目复位成全部项目再过去）。

侧边栏显示在左侧还是右侧由 Chrome 设置控制，可在 Chrome 设置的「外观 → 侧边栏」中修改。

如果快捷键与其他扩展冲突，可在 `chrome://extensions/shortcuts` 中查看或重新设置。macOS 上 `Alt` 对应 `Option (⌥)`。浏览器内置页面、Chrome 应用商店和内置 PDF 查看器等受保护页面不允许扩展注入内容，网页翻译不会在这些页面运行。

快捷键「按了没反应」时，打开设置页的「快捷键」一栏看自检信息：如果「最近一次快捷键触发」始终显示「还没触发过」，说明该组合键被系统或其他软件抢先拦截了（按键没有到达扩展），换个组合键即可；改键不需要重装扩展。另外，右键菜单里的收藏入口不依赖快捷键，随时可用。

**封面**的抓取顺序（任何一层拿到就停）：网站自带的分享图 → `link[rel=image_src]` / `meta[itemprop=image]` → 结构化数据（JSON-LD）→ 视频封面 `poster` → **抖音专用层**（它完全不给分享标签，封面只存在于 `[data-e2e=player-container]` 里，取带 `origin_cover` 标记的原图）→ 页面上的**背景图**（小红书这类站点的内容图属于这一层）→ 懒加载属性（`data-src` 等）→ 页面上最大的图。像平台 logo、占位图、雪碧图、头像、矢量分享图这类明显不是内容的图会被跳过——**这种情况宁可不显示封面，也不显示一张假的**。**摘要**依次取：分享标签 → 结构化数据 → 正文第一段 → 常见的简介容器（`#detail-desc`、`.desc`、`[class*=excerpt]` 等）；**抖音例外**，它的 `.desc` 实测会命中「合集里下一集」的文案，所以抖音不做正文扫描，只保留自家 meta 里真正有用的部分（作者 / 日期 / 热度），其余宁可留空。

**标题**依次取：页面正文里的标题（`h1` 等）→ 分享标签（`og:title` / `twitter:title`）→ `meta[name=title]` → 结构化数据 → 页面标题。**抖音**不写任何标准标签，标题取自 `[data-e2e=detail-video-info] h1`（容器上还带 `data-e2e-aweme-id`，可确认是当前视频），过长时截到 140 字。每个候选都会先**剥掉「 - 站点名」这类尾巴**（站点名的来源包括 `og:site_name`、`application-name`、页头 logo 的 alt、抖音自家 lark 元数据里的品牌名，以及页头页脚里反复出现的品牌短词——最后这一路专治小红书、哔哩哔哩这类从不声明自己名字的中文站点）；剥尾巴的条件收得很紧，所以「React 18 发布 - 前端周刊」这类真标题不会被切坏。如果所有来源都不像样（例如页面还在加载、或标题只是个域名），就**留空**，改用浏览器标签页的标题兜底——**不会**拿域名硬凑一个假标题。重复收藏同一篇时，带尾巴的旧标题会自动被换成干净的。

跨站图片有个坑：小红书等站点的图片 CDN 会拒绝带 `chrome-extension://` Referer 的请求（返回 403），所以四个页面统一声明了「不发 Referer」，封面和站点图标才显示得出来。（抖音的图片实测没有防盗链限制。）

**单页应用（SPA）的「切换滞后」**：抖音这类站点站内切换视频时，网址会**瞬间**变，但标题和封面要**滞后 150–360 毫秒**才跟上（实测数据）。如果在这段窗口里收藏，就会抓到上一条视频。所以收藏时会先探测「网址 / 标题面板 / 平台元数据」三处的视频 id 是否一致，不一致就等到对齐（**上限 1.5 秒**）；抓完还会**复核一次**——提取脚本会回报它实际读到的视频 id，与网址对不上就在剩余时间里重读。非抖音网站完全不做这些额外动作，一秒都不多等；抖音首页、休眠标签也会立刻放行。

某个网页抓不到封面时，打开设置页的「快捷键」自检区看**「最近一次封面来源」**：它会写明封面是从哪一层拿到的（网站分享图 / 背景图 / 视频封面 / 结构化数据…），或者为什么没有可用的封面图（例如「网站的分享图是平台通用图，已跳过」）。

收藏数据存储在 `chrome.storage.local` 中；翻译使用 Chrome 的本机 Translator API，不会把正文发送到第三方翻译服务。
