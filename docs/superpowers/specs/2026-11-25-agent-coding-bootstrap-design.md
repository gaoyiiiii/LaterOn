# Agent-coding 接入设计

- **意图**：为 LaterOn 建立项目级代理协作规则与持久任务记忆，使后续改动按单个任务切片推进。
- **目标**：增加精简 `AGENTS.md` 和 `.agent/MEMORY.md`；记录已验证的 MV3/原生前端项目事实；为本次接入登记一个待办切片。
- **非目标**：修改扩展业务代码、增加依赖或测试框架、猜测未配置的测试命令、创建初始提交。
- **约束**：目录检查表明项目包含 `manifest.json` 与原生 JS/CSS/HTML 文件；当前未发现 `package.json` 或测试配置。全局指令要求使用中文，并遵循 Agent-coding 切片、验证和收尾协议。
- **方案**：可原样复制空模板、最小地填写项目规则与记忆骨架，或广泛扫描并完整逆向建档。采用最小落地方案，避免空模板无指导性，也避免把有限证据扩写成架构断言。
- **实施**：保留已有未跟踪项目文件；写入项目级规则与任务记忆；验证新增文件、Git 状态及 `manifest.json` JSON 有效性。由于没有测试配置，不添加虚构命令。
- **收尾**：任务验证通过后将切片标记完成、删除临时 TODO CSV，并按用户指令提交本次规范接入变更；是否提交初始化的业务文件须避免未经确认的全量暂存。
