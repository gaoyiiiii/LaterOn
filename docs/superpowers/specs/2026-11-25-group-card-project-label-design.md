# 已分组网页卡片显示当前组别

## 意图

用户进入一个组查看网页时，卡片上的所属组控件应反映网页实际保存的组别，而不是默认显示「等待整理」。

## 目标与范围

- 首次创建网页卡片时，将所属组选择控件设为 `item.projectId` 对应的组。
- 未分组网页仍显示「等待整理」。
- 保持现有卡片模板、项目选项和后续卡片同步行为。

本切片不处理添加网页时选择分组的弹窗，也不调整字体或其他卡片交互。

## 约束

- 使用现有原生 JavaScript 与 DOM 结构，不新增依赖。
- 项目未配置自动化测试；按 `AGENTS.md` 运行 manifest JSON 与根目录 JavaScript 语法检查，并明确这不是功能测试。
- 当前修复限于 `library.js` 的卡片初始化逻辑。

## 实现方式

保留 `fillProjectSelect` 生成的选项，在 `createCard` 中填充选项后，将选择值同步到 `item.projectId || ""`。现有的 `updateCard` 逻辑继续负责卡片复用后的组别同步。

另一个可行方案是将组名改为静态标签并另设分组操作控件；这会扩大模板和交互改动，与当前问题无关。用户已批准保留现有控件并初始化当前组别的方案。

## 验收

- 已分组网页首次创建卡片时显示其所属组名。
- 未分组网页首次创建卡片时仍显示「等待整理」。
- Manifest JSON 解析与根目录 JavaScript 语法检查通过。
